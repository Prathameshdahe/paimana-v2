# PAIMANA dashboard

Dashboard for PAIMANA Early Warning Radar. React 19, Vite 6, TypeScript,
Tailwind, TanStack Query and Recharts. Setup, the backend, the model and the
data pipeline are in the [root README](../README.md).

## Commands

From this folder:

```
npm install
npm run dev         # http://localhost:3000, fails if the port is taken
npm run lint
npm run typecheck   # tsc -b
npm run build       # tsc -b, then vite build into dist/
npm run preview     # serves dist/ on port 3000
```

## Backend

`src/lib/api.ts` exports `API_BASE`, read from `VITE_API_BASE` and defaulting to
`http://localhost:8000`. The variable is in the `.env` at the repo root because
`vite.config.ts` sets `envDir` to `..`.

The app works without the backend. It shows the 300 largest projects by
anticipated cost from the 2024-25 data, stored in `src/mocks/real_projects.json`
(generated by `pipeline/build_real_projects.py`) with heuristic risk scores and
drivers. If `GET /api/model-scores` answers within 1.5 seconds,
`src/mocks/index.ts` swaps in the LightGBM probabilities and SHAP drivers.

Expect the picture to change a lot when it does. The risk score becomes slip
probability times 100 with the same 60/30 tier cutoffs, and the median
probability is about 1.7%, so the 300 go from 46 critical / 88 warning / 166
normal to 3 / 25 / 272. The chat widget (`src/lib/queryEngine.ts`) is keyword
search over the heuristic data and keeps using it even with the backend up.

The Worker Console and Approval Inbox call the backend directly and show an
error without it.

## Where things are

Routes are in `src/App.tsx`: `/`, `/login`, `/command`, `/projects/:id`,
`/sandbox`, `/audit`, `/workers` and `/approvals`. The `@` import alias points
to `src/`.

`src/mocks/` holds the real project data, the hardcoded Audit Suite numbers
(`audit.ts`) and the query hooks that apply the model overlay. The role picker
behind `/login` is in `src/lib/auth/`.
